# ai-flavor-detect

## 判据来源（唯一）

规则文件：`${CLAUDE_PLUGIN_ROOT}/references/rules.md`。若 `CLAUDE_PLUGIN_ROOT` 为空（在本仓库内直接使用），则为仓库根目录下 `references/rules.md`。

**每次执行都重新读取该文件全文**，不依赖记忆中的旧版本。本文件不复述任何规则条目；规则以 rules.md 为准。

## 判定原则：严格模式

- 只判 rules.md 中现有的规则（id 形如 `A-01.1` / `B-03` / `C-05` / `D-02` / `G-03`）。
- 不发散、不自创特征、不把"感觉像 AI"但对不上任何规则的地方计入命中。对不上规则的疑虑最多写进"备注"，不进命中清单。
- 遵守 Layer 0 全部红线（R-01～R-06），尤其：永远给疑似度区间，禁止二元判决；所有标点 / 句式特征按密度与分布判，不按"出现即警"。

## 输入

- 直接贴的文本；或一个 / 多个文件路径（多个文件视为多章节，按文件顺序）。
- 可选：用户显式指定文体先验（G-01～G-05）。未指定则自行判定，并在报告中写明。

## 流程

1. 读 rules.md 全文。
2. 判文体先验 G-xx，写明依据。
3. R-04 检查：总字数 <300 字时不单独打分，报告只给"累积参考"并说明原因。字数按汉字数计（不含标点与空白）；英文文本按词数计。
4. Layer A 逐规则扫描（含全部子规则）。每条命中记录：证据原文（逐字引用）、密度 / 分布数据、强度（弱 / 中 / 强）。
5. 多章节输入时跑 Layer B：逐章重复步骤 4/6/7 得到章节分，画"章节-疑似度"曲线，按 B-01 曲线判据判形态；单章输入只判 B-02/B-03/B-04/B-06。因文本类型缺乏证据而无法评估的规则（如无对话时的 B-03 / D-02），不进任何命中列表，在报告"备注"中列为"未评估：[...]"，与"评估过但未命中"区分。
6. Layer C 七项各打 1–5 分并给一句理由。评分 ≤2 视为该 C-xx 命中，**同时写入命中清单的"字面命中"与"有效命中"列表**（Layer C 不参与文体降权）。
7. Layer D 始终逐项评估 D-01～D-06 并记录证据原文（命中清单的"Layer D 命中"永远要填）；当 Layer A 软线索（A-01 / A-02 / A-05 / A-09）命中时，额外执行抵消判定（步骤 9）。
8. 应用排除项子规则 A-04.2、A-06.2：被触发时，把对应的 A-04.1 / A-06.1 字面命中从有效命中中移除，并把 A-04.2 / A-06.2 记入"排除项应用"。A-10.4 **不是**排除项：`[n]` 无对应实质尾注 → A-10.4 命中（字面 + 有效，不降权）；有实质尾注 → A-10.4 不命中，不记入任何列表。
9. 按 G-xx 文体档 + 维度级降权表算**有效命中**：降权后仍超该规则强信号线的才算。若某条规则在 rules.md 中未给出量化的强信号线，按该条"信号 / 检测"描述做定性的密度 / 分布判断（R-05：单次出现不算，须达到"密度异常或分布异常"），并在报告"备注"中标注"定性判定"；不得自创数字阈值。文体先验不在维度级降权表覆盖范围（G-01 / G-04 / G-05）时，对全部 Layer A 命中统一套用该文体档"整体倾向"列的系数（如 G-04 Layer A ×0.7），不自行套用 G-02/G-03 的行。Layer D ≥3 项强命中时，A 类软线索命中按"文体/笔法"降权或抵消。
10. 按 rules.md "评分与定级"公式与锚点表定 0–100 分及低 / 中 / 高。

## 输出（两段都必须有）

### 第一段：报告（遵循 rules.md §0.2）

```
疑似度：低 / 中 / 高（NN 分）
文体先验：G-0x <文体名>（判定依据一句话）
触发规则（扣分）：
  - <id> · 「证据原文」 · 强度 · 是否文体误伤（是/否 + 一句理由）
  ...
反 AI 加分项（Layer D）：
  - <D-id> · 「证据原文」 · 为什么这是人味硬证据
  ...
Layer C 评分：C-01 n（理由）… C-07 n（理由）
建议（给编辑）：
  - 指向具体段落 / 句子的可操作修改，每条对应一个触发规则
备注：对不上任何规则的疑虑、定性判定的规则、未评估的规则清单（可为空）
```

多章节输入另加"章节曲线"表：章 · 分 · 主要触发规则，及 B-01 形态判断。

### 第二段：命中清单（机器可比对，格式固定）

```
## 命中清单
文体先验: G-02
字面命中: [A-01.1, A-09.3, A-02.1, C-01]
有效命中: [A-01.1, A-09.3, C-01]
排除项应用: [A-04.2]
Layer D 命中: [D-01, D-04]
Layer C 评分: {C-01: 2, C-02: 4, C-03: 3, C-04: 4, C-05: 3, C-06: 4, C-07: 5}
疑似度分: 42
```

- 四个列表（字面命中 / 有效命中 / 排除项应用 / Layer D 命中）都用 `[a, b]` 形式，空则 `[]`；Layer C 评分用 `{C-01: n, …}` 字典。"排除项应用"只可能出现 A-04.2 / A-06.2。
- "字面命中"= 步骤 4/6 的原始命中；"有效命中"= 步骤 8/9 之后仍成立的命中。
- 子规则命中只写子规则 id（如 `A-01.1`），不再重复写父规则 `A-01`。
- 多章节输入时，命中清单给全书汇总；各章清单放在章节曲线表下方。

## 硬约束

- 禁止出现"本文是 AI 生成的 / 不是 AI 生成的"任何二元表述。
- 每条命中必须附逐字证据原文。
- 建议必须指向具体段落，不得只给"减少排比"之类的泛泛之词。
- 不修改用户文本；修复交给 `ai-flavor-fix`。
