## 说明

B-03 的检测法在 rules.md 里写得很硬："给主要角色的对话片段，判**能否仅凭说话方式区分角色**"。所以这个 case 的验收方式是：把 before 里的说话人标签全部遮住，判官应当无法把台词分回三个人；after 遮住标签后应当仍能分对。三个角色的身份差异是刻意拉满的——五十五岁的厂长、五十四岁的三十年工龄工人、二十六岁刚来两年的会计——**身份差这么大却说一个腔，正是失真最明显的形态**。

**before 为什么命中**：

1. **同一句式模板轮流复用**。三人的开口方式几乎逐字同构：邵国庆「我认为，我们现在面临的是……」、老雷「但是我认为我们必须面对现实」、林蓓「我认为，我们需要理性地分析当前的形势」。收尾也同构：「因此，我建议……」「因此，我认为我们应该……」。谁说的都一样。
2. **无任何个人语言指纹**。全篇零口癖、零方言、零脏话、零破句、零省略。三十年工龄的车间工人老雷说的是「与之相伴的稳定收入」「从长远的角度来评估这件事情的利弊」——这不是他的词汇表。
3. **两边讨好的中立腔**同样被三人共享：老雷「一方面……另一方面……」、林蓓「确实处于合理区间之内。但是我们同时也要认识到……」。三个利益立场完全不同的人，说出来的是同一种谁也不得罪的会议纪要。
4. **exposition over action（"你知道吗，鲍勃"）**：第三段整段是设定倾倒——「正如你们所知，我们这家印刷厂自一九八七年建厂以来，已经运营了三十七年，目前在册职工四十二人……」。这些数字在场三人全都知道，说出来只为了让读者知道，是 rules.md 点名的"用对话硬塞背景设定"。
5. **过于正式平淡、无潜台词**。三人从头到尾没有人真正反对谁，冲突为零，最后以「那就这样定了」平滑收场——Neil Clarke 的"flat, no subtext"。

**after 改了什么**（只改对白，人物、场景、事件走向不变）：

- **邵国庆**：短、断、回避。开口只报数字（「四千二一个平方。三千一百个平方。你们自己算。」），被追问就「这个……回头再说」，最后表态也只有两个字（「我不定」）。他的信息藏在他不肯说的地方。
- **老雷**：河南口音 + 口癖。「中不中」「弄啥哩」「中中中。我不说了」；句子破碎、跳跃、爱翻旧账（三号机、许昌、拿肩膀顶了三个钟头）；提问方式是逼人表态（「你倒是吭一声」）。
- **林蓓**：术语 + 年轻人的口语碎片。会计的精确（「不是按工龄分的」「后面还有一页，写着'另行商定'」「四〇五〇」「灵活就业社保补贴」），但夹着「那个……我意思是」「我以为……用不上」这样的迟疑毛边。
- 设定倾倒被拆掉：厂龄、职工数不再由人物背诵，只留下计算时用得着的两个数；「三十七年」这类只给读者看的信息一律删除。
- 加入潜台词：老雷问的其实不是补偿款而是「签了以后我干啥去。五十四了」；林蓓那句「我以为……用不上」承认了她早就知道厂子要没；邵国庆坚持不发群里、要"他们能改"，是他二十年来第一次不替人做主，这一层由老雷那句「你要是二十年前也这么说话就好了」点破。

**after 为什么不再命中**：遮住说话人标签后，三种语体互不可换——把老雷那句「弄啥哩这是」放进林蓓嘴里立刻违和，反之亦然。这同时是 D-02（人物声音可辨）与 D-04（口语毛边 / 方言 / 口癖）的正向证据，符合 rules.md 用 Layer D 对冲的思路。

**边界**：判定在两处会翻转。（1）**同腔不等于命中**——如果三个角色本就同源（同一支部队的三个兵、同一实验室的三个研究员），共享行话与句式是真实的，此时该看的是有没有个体差异层（语速、回避模式、谁抢话），而不是词汇表是否重合。（2）**正式不等于失真**——正式场合（庭审、军事简报）的对白本来就该正式；B-03 判的是"正式到抹平了角色间差异"。before 之所以命中，是因为场景是三个熟人在办公室吵一件切身利益的事，却拿出了公文腔。反过来，after 若把老雷的方言口癖加得过密（每句都"中"），会滑向另一种扁平——刻板印象式的口音标签，那是把角色简化成一个音，依然不是可辨的声音。
