## 说明

本 case 是 Layer D 的**正例锚点**：D-04"口语毛边 / 方言 / 口癖"。rules.md 给的理由是"AI 语法过分正确"，它与 Layer C 的 C-03（口语杂质）同源——AI 对白倾向写成完整、规范、无冗余的书面句。验收比对 detect 输出的 `Layer D 命中` 列表是否含 D-04。

**为什么这是人味硬证据**——毛边分四类，都是"语法书上不该这么写、但人就是这么说"的形态：

| 类别 | 文中实例 | 为什么规范化改写会失真 |
|---|---|---|
| 方言词与地域称谓 | 王爹、曹叔、陆哥、宋姐、陆老哥、娃、丫头 | 六种称呼对应六种亲疏与身份判断，改成"王先生""老曹同志"这层关系全丢 |
| 应答口癖复现 | 老曹的"成。""那成。""那行。"（三次）；"我们不留闲人"（在 16 章与村民转述里各出现一次） | 同一人的应答词被复用且带微差（成／那成／那行），是个人语言习惯而非作者随机选词；"不留闲人"被村民原样转述，说明这句是聚落里流传的原话 |
| 破句、省略与不说完 | "撑不了多少天。老曹说了，不留闲人。王爹那样，迟早……"（说到一半停住）／"你……"（哑了）／"够。""她行。""听明白了。"（三个单句应答） | 村民那句的省略号不是修辞，是"这话不好说完"；三个短应答把陆远洲"不讨价还价"的性格压在字数里 |
| 不合书面逻辑的口语句法 | "谁想在这儿待着，就得把手上的活。"（"把"字后缺动词，口语里靠语调补）／"不听也不是不可以，出去就是。"（双重否定＋兜底短句的乡土威胁式）／"留着吧，反正也不吃亏。"（旁人议论的省略主语） | 这些句子直接送进语法检查会被标错；改成规范句立刻变成公文腔 |

两条更硬的证据：

1. **毛边是分层的，不是统一撒的**。老曹是乡村干部：短句、命令式、爱下定义（"规矩是死的"）、说狠话前先打招呼（"丑话说在前头"）；村民是低声、含糊、留半句；宋玉兰说的是"他跟我一个老家的。我看着他想我婶子。"——用亲戚关系解释自己的动摇，是普通人给自己找理由的真实方式；王老汉只剩气音（"你……你不容易。你还有娃。"）。AI 对白的典型塌陷是全员共用同一档口语浓度。
2. **粗粝与体面并存**。老曹撂完"赶出去、出去就是"的狠话，转头在人走时喊一句"陆老哥……可你带着孩子——你替她想想"。同一张嘴的两种腔调不冲突，这是活人；AI 更容易把角色写成单向度的"冷酷管理者"。

**边界**：D-04 判的不是"出现了方言词"。判据是**毛边是否承担人物功能**：撒一把"俺""咋""整"却人人腔调相同，不该命中 D-04。本文的检验方法是把每句对白改写成语法完整的书面句——"我们不接纳没有劳动能力的人""他大概支撑不了太久"——文本会立刻失去说话人。

**为什么 known_other_issues 为空**：本 case 无 `must_not_hit`，text.md 不是"应不命中"侧文本，按 case-common 的字段语义不记录其他规则的字面命中。
