## 说明

C-03 判的是**口语杂质**：低分＝语法过分正确，无破句 / 省略 / 口误 / 方言；高分＝有人的毛边。判官打 1–5 分，≤2 命中。

**before 为什么是 1–2 分**：说话人设定是修车铺师傅，口述场景，但全文没有一处破句、没有一处省略、没有一个方言词。每句都是完整的主谓宾加书面连接词：「我首先对车辆进行了初步的外观检查，随后将车升起，重点观察了底盘部分的情况」「经过仔细排查，我发现问题并不在于车主所怀疑的悬挂系统，而是出在右前轮的轴承上」。名词都用术语的正式形态——"悬挂系统""磨损迹量""进行更换作业""结清费用离开了"。连引述车主的话也被改写成间接引语并书面化（「车主询问了更换的费用和所需的时间」），一句原话都没留。末段是"希望广大车主能够引起足够的重视"，彻底离开了修车铺的语域。语法零失误恰恰是失真：一个师傅口述两个钟头的活，不可能一次都不打岔、不重复、不把话咽回去。我给 **1 分**。

**after 为什么是 4–5 分**：毛边密集且分层——
① **破句与省略**：「没看出啥。升起来。底盘，主要看底盘。」「右前，轴承。」主语宾语大面积省略，短到只剩名词。
② **话说到一半拐弯**：「这玩意儿它不是慢慢坏，它是……哪天说不行就不行了。」「就是那个卡簧，费了点劲——不说了，反正下来了。」后一处是典型的口述跳过：他自己知道细节，判断听的人不需要，直接掐掉。
③ **口语词与方言**：下晌、孬、搓板路、件儿、六百打住、咋整、俩钟头、毛毛的、这玩意儿。
④ **重复与语气冗余**：「他说行行行」「响一点，忍着；再响一点，还忍着」——重复不是修辞，是说话时的自然节奏。
⑤ **直接引语保留了原话**：「"那能不能再顶一阵。"他问。」而不是"车主询问是否可以延后处理"。
⑥ **回答里带情绪与反问**：「上高速上给你抱死一个轮，你说咋整。」
末段收在一句认命的牢骚上（「说了二十年了，该忍的还是忍」），语域自始至终没有跳出修车铺。我给 **5 分**。这同时是 D-04（口语毛边 / 方言 / 口癖）的强正例。

**两版事实层面如何保持一致**：同一件事逐环对齐——① 下午车开进店，车主报"间歇性异响"；② 先外观后升起看底盘；③ 车主怀疑减震（悬挂），实为右前轮轴承，有旷量；④ 归因于十四万公里 + 路况差；⑤ 车主问能否拖，师傅讲安全风险；⑥ 报价：配件约四百，含工时约六百，当天完成；⑦ 实际耗时约两小时；⑧ 试车异响消失，付款离开；⑨ 收尾感慨"该早点来修"。数字（十四万公里、四百、六百、两小时）两版完全相同。after 多出的"卡簧费了点劲""前两天听得我心里毛毛的"属于同一过程的口述颗粒，不改变事件。

**边界**：① **C-03 不等于"必须写方言"**。一个北京编辑写的散文可以毫无方言词而 C-03 得 4 分——靠的是破句、省略、自我打断。反过来，把方言词当标签均匀撒在每句话上（每句都"中""咧"），会滑向刻板印象式的口音贴纸，判官应下调而非上调，这与 B-03 的边界一致。② **文体先验**：说明书、法律文书、公文本就要求语法完备，此类文体下 C-03 应大幅降权甚至跳过（见 rules.md R-02/R-03）；本 case 的文体设定是**口述实录**，正是 C-03 最该生效的场景。③ before 的 C-01（具体细节密度）并不低——十四万公里、四百、六百、两小时都在——变量已隔离在 C-03 上，不构成连带命中。
