## 背景

- **文体**：行业调研报告的结论节，非虚构、说明 / 议论体，写给项目自己人看。文体先验应判为 G-01（公文 / 说明书）或 G-05（营销 / 公关稿）之间；判定时须写明取哪一档及依据。
- **场景**：定制写作行业调研的阶段性总报告，本节列出五条核心结论。
- **约束**：两版事实、数据、专名、结论完全一致，只在格式与措辞上有差别。数字（1768 粉、0.08–0.1 元/字、20万字6万）一个不动。

## 覆盖的规则

这是五个定性 case 里**唯一的非虚构样本**，专门覆盖小说文体里几乎不出现的三条规则：

- **A-11 格式化强迫**：531 字里 12 处 `**加粗**`、6 条 bullet，且加粗大量落在整句上（「**没有一个等于"个人花钱请人写一本专属小说"。**」「**这是路线 A 的首选现金流品类**」），属条目所述"内容不长却拆成项目符号 / 加粗滥用"。
- **A-10.3 Unicode 装饰**：`→`（「种草→私域闭环」）与 `⭐`（小标题末尾）。注意这是**硬证据类**规则，rules.md 说"出现即基本实锤"，误判风险低——但本例是给自己看的内部文档，装饰符是顺手打的。**这正是要测的**：A-10.3 在"作者本人内部笔记"这一场景下会不会误伤。
- **A-06.1 三点式 / 总分总强迫**：「最核心的五个结论」+ `### 1.` ～ `### 5.` 编号，且每条都是"结论句 + 加粗补充"的同构段落，段落长度高度接近。
- **A-04.1 八股词**：卡位、赛道、闭环、种草、私域、降维打击、壁垒、品类、体量、起量、窗口期、催熟——现代商业八股词密集。

**这个样本要回答的问题**：G-01 整体降权 ×0.5 是否会把 A-11 / A-10.3 这类"格式硬证据"一起压掉。按 R-03 的维度级降权表，A-10 / A-08 在 G-02 / G-03 下是 **×1.0 不降权**，但**该表没有 G-01 这一列**——G-01 只有文体档表里的"整体降权 ×0.5"。detect 的流程第 9 步规定"文体先验不在维度级降权表覆盖范围时，对全部 Layer A 命中统一套用该文体档整体倾向系数"，即 A-10.3 也要 ×0.5。这与 A-10"出现即基本实锤"的定性描述冲突。本 case 就是要把这个冲突暴露出来。

**刻意保留的**：

- 全部数字、平台名、竞品名（小忆舟、席地而作、时光执笔、自传语伴）、报价区间——这些是 D-01 / D-05 的实指归因证据，一个不动。
- 「### 1.」～「### 5.」的小标题层级。这是一份**报告**，分条本身是体裁需要；A-06.1 判的是"任何话题默认组织成三点"的强迫感，不是"报告不许分节"。真正过量的是每条内部又叠加粗 + bullet，所以修的是内部，不是骨架。
- 直接引语「'整理文字'和'创作回忆录'是两种完全不同的服务」——实指归因（D-05）。

## 已知的其他问题

- before 与 after 都保留了 markdown 标题符 `##` / `###`。按 A-10.1，`##` 属"markdown 残留"——但那是**针对小说正文里混进 markdown** 的场景。这里文本本身就是 markdown 文档，标题是体裁的一部分，不应计为机制性露馅。若 detect 把两版的 `##` 都判成 A-10.1 命中，属误判；因两版同等含有，不影响比序，但应记入回归结果备注。
