# AI 味特征检测清单 v3.1

> 🔑 **核心交付物**。这份清单列出"哪些写法会**让网友把你认成 / 指认为 AI**"，供审查 Agent 执行。
> 日期：2026-09-07（v3.1：主观样本新增 A-01.4 / A-12，收窄 A-01.3）　｜　回归集：见 regression/cases/

---

## 0.0 本清单判的是什么（先读，定调）

**目标不是"科学地识别 AI 文本"，而是"判断写好的东西会不会让人觉得有 AI 味"。**

这是一个**主观判据**，不追求科学上的客观可证伪性。判据来源有两类，本清单只认这两类：

- ❌ **不认**：困惑度、突发性、BERT、词频 Z 分数、AI 检测器结论……这些回答的是"文本客观上是不是 AI 生成的"，不是我们要的问题。（**它们不构成本清单的判据**。）
- ✅ **认可来源一：舆论实证**——网上**真实发生的争议、吐槽、鉴 AI 事件**，即"网友实际上会因为哪些写法指认你是 AI"。
- ✅ **认可来源二：个人主观感受样本**——维护者本人在日常阅读 AI 生成内容时，主观感受到"AI 味"的具体示例。这类样本没有网友群体讨论作为佐证，但同样是有效判据来源，因为本清单的目标本就是主观阅读感受，不是客观检测。

**一条特征能否进本清单的标准：有真实网友吐槽 / 指认过 AI（来源一），或有维护者本人在阅读中主观判定为"AI 味"的具体示例支撑（来源二）。** 两类来源同样有效，缺一不可比谁更"硬"；只是统计上"AI 多用"但既无舆论实证也无主观样本支撑，不进。

> 这带来一个重要推论：**"科学上不显著"不等于"对我们的目标无效"**。破折号就是典型——统计上 AI 用得比真人少，但网友确实因此指认作者（妩梵事件、博主被骂），所以它仍是有效风险信号。判据是舆论事实 + 主观阅读感受，不是统计显著性。

> 两类来源在证据强度标注上应予区分（供 skill 3 更新规则时使用）：来源一的案例可标注为"舆论实证"，来源二的案例应标注为"主观样本"并注明由谁在何种场景下提出，避免日后误当成有群体共识支撑的舆论案例。

## 0. 怎么用这份清单

### 0.1 检测分四层

| 层 | 检测对象 | 实现方式 | 角色 |
|---|---|---|---|
| **Layer A** | 句式 / 词汇 / 结构 / 标点——文本表面特征 | 正则 + 统计（本地可算，快、便宜） | 硬线索，第一道筛 |
| **Layer B** | 叙事 / 人物 / 长程一致性——**小说 / 长篇特有** | 结构化统计 + LLM-judge | 抓"前精后 AI"、上下文崩塌 |
| **Layer C** | 信息密度 / 立场 / 情感 / 个人声音——风格性弱点 | LLM-judge 提示词评分 | 兜底，抓规则抓不到的"感觉不对" |
| **Layer D**（v2 新增） | **反 AI / 人味加分项**——具体细节、人物声音、伏笔回收等"一眼真人"硬证据 | LLM-judge | **反向降噪**：当 Layer A 软线索命中时，用 D 的强证据**抵消误伤** |

> v2 为何加 Layer D：实测发现，原清单只有扣分没有加分，导致强文体强人味的文本被 A-02/A-09 误伤时无处抵消。Layer D 记录"网友一眼能认出是真人写的"特征，用来对冲 Layer A 软线索。

### 0.2 输出规范（强制）

审查 Agent 的输出**必须是**：

```
疑似度：低 / 中 / 高  （+ 0–100 区间分，按 §"评分与定级"的锚点校准）
文体先验：[小说/文学 / 古典·文白 / 现实主义 / 散文 / 公文 / 应试 / 营销 / 未知]
触发维度（扣分）：[A-01, A-07, ...]   每条带：维度ID · 命中证据原文 · 强度 · 是否文体误伤
反 AI 加分项（Layer D）：[D-01, D-03, ...]   每条带：证据原文 · 为什么这是人味硬证据
建议：给编辑的可操作修改建议（指向具体段落），而非"这是 AI 写的"
```

**绝不输出"本文是 AI 生成的"这种二元判决。** 理由见 Layer 0。

## Layer 0 — 误判保护红线（审查 Agent 必须先内化）

> 一个会"乱杀"的审查 Agent 比没有更糟。以下是基于研究 + 4 本书实测的硬性约束。

| ID | 红线 | 说明 | 落地 |
|---|---|---|---|
| **R-01** | 永远是疑似度，不是判决 | OpenAI 自己的 Classifier 2023 年下线，准确率仅 26%，连《美国宪法》都被判 AI。任何单一特征都不能定罪。 | 多维度加权 + 输出区间分 |
| **R-02** | 文体先验调阈值 | 不同文体天然命中不同判据，必须先判文体。 | 见下方"文体先验档"表 |
| **R-03** | 降权细化到维度级（v2 修订） | v1 的"小说 Layer A ×0.6"一刀切太粗——A-10/A-08 在小说里出现即硬伤（不该降权），而 A-01/A-02/A-09 在文学里该降更多。 | 见下方"维度级降权"表 |
| **R-04** | 短文本不判 | <300 词的段落准确率接近随机猜（Turnitin 设 300 词下限）。 | 单段 <300 字不单独打分，只做累积参考 |
| **R-05** | 区分"出现"与"密度异常 / 分布异常" | 单个破折号、单个"不是…而是"无害；致命的是**密度**和**分布**（见 A-09 的分布判据）。 | 所有标点 / 句式特征用"密度阈值 + 分布"而非"出现即警" |
| **R-06** | 不依赖单一特征下定论 | 网友鉴 AI 本身是主观、多线索的；且科学检测本身不可靠（OpenAI Classifier 准确率仅 26%）。 | 多维度加权，配合 Layer D 反向降噪；一个特征只贡献一分 |

### 文体先验档（R-02）

| ID | 文体 | 整体倾向 | 说明 |
|---|---|---|---|
| **G-01** | 公文 / 应试 / 说明书 / 非母语 | **整体降权 ×0.5** | 天然命中"低困惑度、低突发性、词汇多样性低"——斯坦福实测 AI 检测器对非母语者误报率 61.3%（最差 97.8%） |
| **G-02** | 小说 / 文学 / 散文 | Layer B/C 升权 ×1.3 | AI 味核心在叙事与人物，不在词频 |
| **G-03** | **古典 / 文白相间 / 古风**（v2 新增） | 见维度级降权表 | 排比 / 对偶 / 四字短语 / 文言词是文体基底，不是 AI 味——实测验证这是误伤重灾区，见 case G-03-01 |
| **G-04** | 现实主义 / 朴素叙事 | Layer A ×0.7 | 用词朴素本就接近"低 AI 味"基线 |
| **G-05** | 营销 / 公关稿 | Layer A ×1.2 | 本就是 AI 重灾区，正向加权 |

### 维度级降权（R-03，叠加在文体档之上）

| 维度 | G-02 小说/文学 | G-03 古典·文白 | 说明 |
|---|---|---|---|
| A-10 机制露馅 / A-08 开头模板 | **×1.0（不降权，出现即警）** | ×1.0 | 小说里出现 markdown 残留就是硬伤 |
| A-01 否定式 / A-02 排比 / A-09 破折号 / A-12 短句收束 | ×0.5 | **×0.3** | 文学修辞 / 古典文体基底，最易误伤 |
| A-04 口头禅 / A-05 辞藻 / A-06 三点式 | ×0.6 | ×0.4 | A-04 古典文体里文言词会被误抓 |
| A-03 句长方差 / A-07 升华 / A-11 格式 | ×0.6 | ×0.6 | — |

> 降权后若仍超阈值（见各条"强信号线"），才计为有效命中。**任何 Layer A 命中都应先查 Layer D 是否有反向证据对冲。**

## Layer A — 通用文本特征（规则可程序化）

> 每条：**信号 · 检测方法 · 诊断价值 · 误判风险 · 出处**。
> 诊断价值 / 误判风险均为 `低/中/高`。标 ⚠️ 的是高频误判点，必须按密度 + 分布判。

### 句式层

#### A-01　"不是 X，而是 Y" / 否定式排比　⭐最高频
- **信号**：中英文社区一致认定为**最具诊断性的单一修辞**（英文 negative parallelism，"最突出的 AI 写作特征"）。
- **⚠️ v2 必须区分三种结构**（实测文学文本用的多是第三种文学变体，一概而论会严重误伤）：

| ID | 结构 | 形态 | 风险 |
|---|---|---|---|
| **A-01.1** | `不是 X 而是 Y` | 一句话内连续套用 + "而是"连接 | **高**（AI 公式） |
| **A-01.2** | `不是 X，而是 Y` | 逗号连接，议论文正常使用 | 中（看密度） |
| **A-01.3** | `不是 X。是 Y` / `不是 X，不是 Y。是 Z` | **句号断开的短句节奏**，**对照内容为情感 / 认知的重估**（"不是释怀。是终于死心了。"），文学性辨析 / 悲剧揭示 | **低**（张爱玲/余华式传统修辞，见 case A-01.3-01）；对照内容退化为事实信息时归 A-01.4 |
| **A-01.4** | 形态与 A-01.3 相同（含动词否定变体 `不看 X。……看的是 Y`），**仅以对照内容区分**；中间解释句非必需 | 否定—（解释）—肯定拆成两三句，**对照内容是事实 / 信息层面**（预报 vs 实况、命令 vs 口头通知、有序用电 vs 停电），用文学拆句节奏包装平淡对照；是 A-01.1 被"去 AI 味"改写后的常见残留形态（v3.1，主观样本） | **中**；工作阈值 ≥3 处/千字，见 case A-01.4-01 |

- **检测**：先按上表分形态，再算密度。强信号线：**A-01.1 ≥1/千字** 或 **A-01.1～A-01.3 合计 ≥2/千字**；**A-01.4 ≥3 处/千字**（工作阈值）。全书癖好级堆叠见 case A-01.1-01。
- **诊断价值**：高　**误判风险**：高（文学/古典文体常用，必须按形态 + 密度 + Layer D 对冲）
- **出处**：虎嗅 / 知乎《哪些话一出现就知道是 AI 写的》/ Vollmer 引 Blake Stockton / Ruben Hassid 公式 #4 / case A-01.1-01 / case A-01.3-01

#### A-02　强制排比 / 同句式重复
- **信号**：`Fast. Simple. Effective.` 式三连；中文 `当……当……当……`（DeepSeek 标志，必用分号隔开）。虎嗅实测 AI 对偶句平均 4 次/篇，真人学生范文仅 0.67 次——**少有的中文量化对照**。
- **子规则**：
  - **A-02.1** 分号式工整排比：`Fast. Simple. Effective.` 三连 / 中文 `当……；当……；当……`（DeepSeek 标志）。
  - **A-02.2** 同句首 / 同句式重复 ≥3 次，不限分号式（v2 扩展，如同一段内"他想起"×5，见 case A-02.2-01）。
- **检测**：统计分号排比 + 同句首/同句式重复频次。
- **诊断价值**：高　**误判风险**：中-高（政论/演讲正常；**古典/骈文文体是基底修辞，按 R-02/R-03 降权**）
- **出处**：虎嗅实测 / 知乎 DeepSeek 味 / Colin Gorrie / 古典人物声音的排比不算 AI 排比，见 case G-03-01

#### A-03　句长方差过低（低突发性 Burstiness）⚠️
- **信号**：句句长度接近、节奏均匀。学术数据：AI 句法突发性 ~1.6，人类 ~4.4。
- **v2 文体前置**：**本条仅适用于说明文 / 议论文 / 营销文**。叙事文学天然长短句交替，小说场景**直接跳过或仅作极弱参考**（实测小说样本全部不命中，高突发性反而是人味证据，见 case D-06-01）。
- **检测**：算句长标准差 / 变异系数。
- **诊断价值**：中（非小说）/ 不适用（小说）　**误判风险**：高
- **出处**：GPTZero / Sean Kernan / diva-portal 学术论文

#### A-12　表演性短句收束（v3.1 新增，主观样本）
- **信号**：段落或语义单元**规律性**地以 ≤10 字短句收尾（"每天都挂着一个零。""没有影子，无处可躲。""他住十四层。"），或整段只由两句短句构成，形成可预测的"铺垫 → 轻判断"节奏；读者感受为"模仿海明威 / 余华腔"。常与 A-01.4 伴生（去 AI 味改写后保留的"点睛"习惯）。
- **与 D-06 的区别**：D-06 是不规则的长短句交替（人味）；A-12 是**每段一收的规律性**。判 A-12 前须先看是否更符合 D-06。辅助判据：短句收尾的段落连续或均匀分布于全篇为规律性（A-12）；集中在一处为 D-06 侧的节奏变化。
- **检测**：统计**段末小句**（段落最后一个以逗号 / 句号切分出的小句）≤10 字且为独立起头的轻判断 / 点睛句的段落占比。工作阈值：**≥40% 段落且 ≥3 段**（主观样本，见 case A-01.4-01：按此口径 before 为 11 段中 5 段）。
- **诊断价值**：中　**误判风险**：**高**（短句收束是合法文学笔法；G-02 下 ×0.5，须查 Layer D 对冲）
- **出处**：主观样本（维护者阅读判定，2026-09-07）/ case A-01.4-01

### 词汇层

#### A-04　AI 高频"口头禅"密度
- **中文经验清单**（缺大样本统计，为社区经验值）：
  > **开头套话**：在当今……的时代 / 随着……的发展 / 毋庸置疑 / 不可否认
  > **过渡**：不仅……而且 / 值得注意的是 / 与此同时 / 更重要的是 / 由此可见 / 在……的背景下
  > **总结**：综上所述 / 总而言之 / 通过以上分析
  > **号召收尾**：让我们一起…… / 希望这篇文章能帮到你
  > **学术八股**：首先 / 其次 / 再次 / 最后；关键在于 / 我们需要
  > **翻译腔万能词**：稳、硬、推、强（强能力 / 强抓手 / 强支撑）；探索；赋能 / 沉淀 / 闭环 / 底层逻辑 / 长期主义
- **英文实证清单**（有 Z 分数支撑，Kobak et al. 2025《Science Advances》）：
  > delve (r=28.0) / underscores / showcasing / pivotal / intricate / meticulously / realm / tapestry / landscape / navigate / testament / leverage / foster / seamless / robust / paradigm / it's important to note / it's worth noting
- **⚠️ v2 词表边界**：词表**限定为"现代语境公文/营销/AI 八股词"**。文言常用词（此间 / 此世 / 穷理 / 格物 / 足下 / 然 / 之 / 乎）和题材术语是**白名单**，不计入（理学题材反复出现穷理/格物是题材必需，与"值得注意的是"不同维度，见 case A-04.2-01）。
- **子规则**：
  - **A-04.1** 现代八股词表命中（上方中文经验清单 + 英文实证清单），按每千字命中数算密度。
  - **A-04.2** 白名单排除：文言常用词（此间 / 此世 / 穷理 / 格物 / 足下 / 然 / 之 / 乎）与题材术语不计入 A-04.1。
- **检测**：维护词表，按"每千字命中词表词数"算密度。
- **诊断价值**：高　**误判风险**：高（营销/公文/学术文体本就高频；古典文体文言词被误抓）→ 按文体降权；易被改写绕过
- **出处**：Kobak arXiv:2412.11385 / Ruben Hassid 禁用词库 / 知乎专栏 / 虎嗅

#### A-05　华丽辞藻堆砌但无实质（"华美的空洞"）
- **信号**：形容词密度过高，"像把自己知道的华丽辞藻都用上"。春田中文网编辑硬规则："一句话中形容词多于三个，基本可判定 AI 文"。
- **检测**：算形容词 / 总词数比；开篇环境 / 外貌描写占比。
- **诊断价值**：中-高　**误判风险**：中（言情 / 古风文体正常；克制型文学文本会被硬套规则误伤，见 case A-05-01）
- **出处**：网文编辑访谈（潮新闻 / 经济观察报）/ CSDN

### 结构层

#### A-06　三点式 / 总分总结构强迫
- **信号**：任何话题默认组织成三点；每段主题句开头 + 总结句收尾；段落长度高度接近。
- **v2 文体前置**：**本条主要适用于说明文 / 教程 / 议论文**。长篇小说几乎不出现"首先/其次/最后"，小说场景基本无效（实测小说样本 0 命中）。注意与"古典论辩枚举"（"其一其二其三 + 带反转/落在人物动作上"，见 case A-06.2-01）区分，后者是人物声音不是 AI 总分总。
- **子规则**：
  - **A-06.1** 总分总标记词：`首先/其次/最后`、`第一/第二/第三`、编号列表，及段落长度变异系数过低。
  - **A-06.2** 排除：古典论辩枚举（"其一其二其三 + 带反转 / 落在人物动作上"）是人物声音，不计入 A-06.1。
- **检测**：统计 `首先/其次/最后`、`第一/第二/第三`、编号列表频次；算段落长度变异系数。
- **诊断价值**：高（非小说）　**误判风险**：中
- **出处**：Wikipedia Signs of AI writing / 知乎专栏 / dev.to / case A-06.2-01

#### A-07　结尾强行升华 / 强制总结
- **信号**：末段突然拔高到"宏大意义 / 时代变化 / 未来展望"；`In conclusion / 综上所述 / 通过以上分析我们可以看出`。"非得来个畅想美好未来的结尾，戏很多且无法让它闭嘴。"
- **子规则**：
  - **A-07.1** 硬总结词升华：末段 `综上所述 / 总而言之 / 通过以上分析 / In conclusion` + 拔高到宏大意义。
  - **A-07.2** 软升华：末段以短句 / 单字揭晓式收束（如 `那个字是——"活"`）且该字是抽象主题词（爱/活/光/家/希望），是 A-07 的文学化变体，硬正则抓不到，须过下方三层检验（经 case A-07.2-01 / case A-07.2-02 双锚点校准）：
    1. **单字揭晓式结构 + 抽象主题词**——有"那个字是——X / 答案是——X"式揭晓结构 + X 是抽象主题词（爱/活/光/家/希望）。mere 描述句不算（如"星只是亮着"的"星"是具体物象、"亮着"是感官动作，无主题指针）。
    2. **末句抽象度突跃高于本章均值**——本章主体具象、末段突跳到主题陈述。
    3. **earned 判据（v2.1 细化）**：看 **"揭晓结构"全章仅此一处**（不是看主题词出现次数）。即便主题词前文出现过，只要揭晓式结构（"那个字是——"）全章唯一，仍算命中——这防止"前文写过'活'所以结尾升华不算 AI 味"的错误开脱。
    - 三层全过 → 命中（60 档，见 case A-07.2-01）；不满足 → 合法 coda（无揭晓结构 / 无主题词 / 抽象度下降，三层全不过，15 档，见 case A-07.2-02）。
- **检测**：末段正则匹配总结词 + 末句抽象度突跃软检测 + 三层检验。
- **诊断价值**：高　**误判风险**：低-中（严肃文学合法 coda，靠三层检验区分）
- **出处**：人人都是产品经理 / 知乎专栏 / Vollmer / case A-07.2-01 + case A-07.2-02 双锚点校准

#### A-08　开头模板化
- **信号**：前 50 词命中 `在当今.{0,10}时代` / `随着.{0,15}的发展` / `In today's fast-paced world` / `Navigating the ... landscape`。
- **检测**：开头窗口正则。
- **诊断价值**：中　**误判风险**：低
- **出处**：知乎 / Wikipedia

### 标点 / 格式层

#### A-09　破折号（舆论强信号，别被统计误导）
- **信号**：公众印象里，破折号（尤其一段话里挤着 2 个以上、用破折号附挂解释性长从句）= AI 头号标记。
- **⚠️ 统计反转**：虎嗅实测 AI 文本破折号占比 **0.58% < 真人 0.85%**——科学上 AI 用得更少。**但对我们的目标仍是有效风险信号**：网友确实因此指认作者（妩梵被空口鉴 AI、博主用 2 个破折号就被骂）。
- **子规则**（v2 新增"分布"判据）：
  - **A-09.1** 密度：一段内 ≥2 个破折号、或全篇密度异常。
  - **A-09.2** 分布：均匀分布于全篇（风格一致，变异系数低）= 个人笔法，降权；集中在某章 / 某段突现 = 更像 AI，升权。
  - **A-09.3** 复合：破折号 + 紧跟解释性长从句 + 与 A-01 嵌套（`不是 X——是 Y`），是头号复合风险，见 case A-09.3-01。
- **检测**：破折号密度 + 用法分类（附挂解释从句 / 叙事停顿 / 句读替代）+ 全书分布变异系数。
- **诊断价值**：中-高（舆论）　**误判风险**：高（文学文体大量使用属正常；意义是"提醒作者这是网友高敏触发点，斟酌使用"，非"用了就是 AI"）
- **出处**：虎嗅实测 / 妩梵事件 / 微博"AI 文风太好认"热搜 / Plagiarism Today 六模型测试 / The Ringer / case A-09.1-01 / case A-09.2-01

#### A-10　机制性"露馅"（硬证据）
- **信号**：残留 markdown 标记（`**`、`##`、` ``` `）；残留 AI 引导语（`根据参考资料 / 以下是续写内容 / 如果你需要我可以帮你 / 希望对你有帮助 / It's important to note`）；Unicode 装饰（`→` `•` `𝗯𝗼𝗹𝗱`）；位置不当的智能引号。
- **子规则**：
  - **A-10.1** markdown 残留：`**`、`##`、` ``` `。
  - **A-10.2** AI 引导语残留：`根据参考资料 / 以下是续写内容 / 如果你需要我可以帮你 / 希望对你有帮助 / It's important to note`。
  - **A-10.3** Unicode 装饰（`→` `•` `𝗯𝗼𝗹𝗱`）、位置不当的智能引号。
  - **A-10.4** 脚注白名单（v2 新增）：`[n]` 编号 + **有对应实质尾注内容**的学术/严肃文学脚注（理学 / 科学 / 历史考据、章末实引文献，见 case A-10.4-01）属体裁设计，**不计为机制性露馅**；判据：检测到 `[n]` 时检查是否有对应尾注正文，无内容才算残留。
- **检测**：正则扫这些字符串 + 脚注内容校验。
- **诊断价值**：高（出现即基本实锤）　**误判风险**：低
- **出处**：知乎 pansz / 番茄金番作者"根据参考资料中的 4016 章"翻车 / Vollmer / case A-10.4-01

#### A-11　格式化强迫（非内容需要也拆 bullet / 加粗 / emoji）
- **信号**：内容不长却拆成项目符号；标题滥用 Title Case；营销 emoji（🚀🔑💡✅）。
- **检测**：bullet / 加粗密度 vs 内容长度。
- **诊断价值**：中　**误判风险**：低（小说里几乎不出现，出现即警）
- **出处**：Sean Kernan / Charlie Guo / Vollmer

## Layer B — 小说 / 长篇特有特征

> ⚠️ 用户的核心场景是**小说**。这一层比 Layer A 更重要，但更难程序化，多依赖结构化统计 + LLM-judge。

#### B-01　"前精后 AI"——章节级疑似度跳变　⭐小说最强信号
- **信号**：长篇连载最典型的灰产——核心设定 + 开篇十几章人工精写骗签约 / 流量，读者规模起来后转 AI 续写。**整书均值会被开篇稀释，必须按章节滑窗检测**。
- **v2 曲线判据**：画"章节-疑似度"曲线后——
  - **单调上升**（越往后越 AI）= 命中 B-01（灰产转 AI 续写）；
  - **U 型 / 波动**（开篇风格化、中段低位、收尾上扬）= **文学合法的节奏安排，不算命中**（开篇风格化、中段低位、收尾单点突跃，是 U 型，非前精后 AI）；
  - **全书平稳高位** = 风格化笔癖（如 A-01 全程 tic），不是 B-01，归 Layer A。
- **检测**：对每章单独跑 Layer A/C 打分，画曲线，看形态。
- **覆盖说明**：全书级规则，需多章节上下文；回归集不覆盖，仅在多章节输入时由 `ai-flavor-detect` 判定。
- **诊断价值**：高　**误判风险**：低
- **出处**：番茄编辑访谈（经济观察报）

#### B-02　长程上下文崩塌
- **信号**：长篇越往后越暴露——人物性格漂移、已死角色复活、设定前后矛盾、人名地名混乱、"AI 不会数数"（前文说四个字，后文写"对这五个字震惊"）。
- **检测**：LLM-judge 跨章一致性检查（人物档案 vs 后文行为、伏笔是否回收、计数 / 名词一致性）。重点关注"该回收没回收的伏笔""被重点描写却没用上的道具"。
- **诊断价值**：高　**误判风险**：低
- **出处**：番茄读者李岩吐槽 / 化名作者 / 吴珊"AI 不会数数"

#### B-03　人物声音扁平 / 对话失真
- **信号**：角色说话一个腔调，没有个人语言指纹（口癖、方言、回避模式、教育背景差异）；对话过于正式平淡；"你知道吗，鲍勃"式用对话硬塞背景设定（exposition over action）。
- **检测**：LLM-judge——给主要角色的对话片段，判"能否仅凭说话方式区分角色"。
- **诊断价值**：高（小说核心）　**误判风险**：中
- **出处**：Vollmer E2/E4 / Clarkesworld Neil Clarke"boring, flat, no subtext"/ CSDN

#### B-04　爽点 / 套路错位（网文特有）
- **信号**：AI 模仿网文套路表面像、内核错位——爽点没爽到、打脸打不到点上、章末钩子高度同质化（按"扫榜拆书→流行爽点→章纲"批量产出所致）。
- **检测**：LLM-judge——"本章承诺的爽点是否兑现""章末悬念是否生硬"。
- **诊断价值**：高（网文场景）　**误判风险**：中
- **出处**：钛媒体 / 知乎网文圈讨论 / CSDN

#### B-05　篇幅拉长后"抽风"
- **信号**：开篇还行，越写越——语言浅白生硬、重复排比、大量内心独白、堆砌无意义环境 / 心理描写。
- **检测**：与 B-01 同一条曲线，叠加"重复用词 / 内心独白占比"随章节上升趋势。
- **覆盖说明**：全书级规则，需多章节上下文；回归集不覆盖，仅在多章节输入时由 `ai-flavor-detect` 判定。
- **诊断价值**：中-高　**误判风险**：低
- **出处**：人人都是产品经理实测

#### B-06　情感"天气化" / 比喻错配
- **信号**：`雨轻轻拍打窗棂，映照她未言说的哀伤`——用环境强行外化情绪；比喻"方向对但物理不对"（`逻辑的河流在她心灵的花园里绽放`）。
- **检测**：LLM-judge。
- **诊断价值**：中　**误判风险**：中（文学手法本身合法，看密度）
- **出处**：Vollmer E6/E8 / Charlie Guo

## Layer C — LLM-judge 软维度（风格性弱点）

> 这些很难用规则判，写成提示词让 LLM 对每项打 1–5 分。这些是 AI 文本的"完美中的缺陷"。**高分即等于 Layer D 的人味证据。**

| ID | 维度 | AI 的典型表现（低分项） | 真人对照（高分项） |
|---|---|---|---|
| **C-01** | **具体细节密度** | 满篇抽象概念，没有具体的人名 / 数字 / 场景 | "没有星期二、没有洗衣店、没有含特定薄荷味咳嗽糖的祖母"——有 Tuesday, laundromat, grandmother |
| **C-02** | **立场明确度** | 两边讨好，`on one hand... on the other`，"正确的废话"，永远中立 | 赞成谁、反对谁、优先做什么，说得清 |
| **C-03** | **口语杂质** | 语法过分正确，无破句 / 省略 / 口误 / 方言 | 有人的毛边 |
| **C-04** | **情感真实度** | 套路化情绪词，浮于表面 | 有情绪漂移（分析→愤怒→温柔） |
| **C-05** | **个人声音** | 没有"我"的独特视角 / 偏见 / 怪癖 | 一眼能认出是谁写的 |
| **C-06** | **信息密度** | 用 200 字说清 50 字的事，填充词多 | 干脆 |
| **C-07** | **归因实在性** | `很多人认为 / 研究表明 / 业内普遍认为`——空指 | 谁、哪项研究、哪个行业 |

> 编辑向审查 Agent 喂稿时，C 维度的提示词可参考 Sean Kernan 给人类的反向建议："用具体名字和数字、感官细节、比喻、幽默、转折"——Agent 反过来检测这些是否缺席。

## Layer D — 反 AI / 人味加分项（v2 新增）

> 这些是"网友一眼能认出是真人写的"硬证据。**命中即降疑似度**，专门用来对冲 Layer A 软线索的误伤。当 Layer A 命中但 Layer D 同时强命中时，应优先判为"文体/笔法，非 AI 味"。

| ID | 加分项 | 为什么是"人味硬证据" | 实测样本 |
|---|---|---|---|
| **D-01** | **具体细节**：品牌 / 药品名 / 数字 / 地址 / 物件 | AI 倾向抽象，真人有"Tuesday, laundromat, grandmother" | 见 case D-01-01 |
| **D-02** | **人物声音可辨**：多角色仅凭对话可区分 | AI 对话扁平同腔（Neil Clarke："flat, no subtext"） | 见 case D-02-01 |
| **D-03** | **长程伏笔回收 / 意象系统咬合** | AI 长篇最易崩的是上下文，回收精密=强反证 | 见 case D-03-01 |
| **D-04** | **口语毛边 / 方言 / 口癖** | AI 语法过分正确 | 见 case D-04-01 |
| **D-05** | **实指归因**：真实文献 / 可查考据 | AI 高频编造论文与链接 | 见 case D-05-01 |
| **D-06** | **句长高方差（高突发性）** | 反 A-03；真人节奏起伏 | 见 case D-06-01 |

**用法**：Layer A 软线索（A-01/A-02/A-05/A-09/A-12）命中时，强制检查 D-01~D-06。若 ≥3 项强命中，该 A 类命中按"文体/笔法"降权或抵消（解决古典文体、文学修辞被误伤的问题，见 case G-03-01 / case A-01.3-01）。

## 模型指纹速查（用于缩小怀疑范围，非定罪）

> 不同模型有不同"修辞偏好"，识别指纹有助于给编辑更精准的"去味"建议。**注意：指纹会随版本漂移，靠 monitoring 更新。**

| 模型 | 典型指纹 |
|---|---|
| **DeepSeek** | "赛博浪漫散文"；`当……当……当……`三段排比必用分号；计算机 / 科技术语修饰情感；中文用户称"一眼 DeepSeek" |
| **ChatGPT (GPT-4 系列)** | `不是 X 而是 Y`；说教式结尾；`delve / tapestry / it's important to note`；破折号附挂从句；热情客服腔 |
| **Claude** | hedge-and-reassure（`while this may vary, generally speaking...`堆叠对冲）；谨慎、礼貌、不愿下判断 |
| **文心一言** | 拟人句、引用句偏多 |
| **腾讯元宝** | 对偶句、排比句偏多 |
| **智谱清言** | 排比句偏多 |

出处：虎嗅 7 模型实测 / 新浪财经 / Colin Gorrie。

## 评分与定级（v2 加分数锚点，解决多 agent 刻度漂移）

```
疑似度分 = [ Σ(触发维度 诊断价值 × 命中强度) − Σ(Layer D 加分项 × 强度 × 抵消系数) ]
         × 文体先验系数（见 R-02 文体档表 + R-03 维度级降权表）

低：分 < 30　｜　中：30–60　｜　高：> 60
```

### 分数锚点（v2 新增——给"0–100"一个可复现的刻度）

> 实测发现：多个 agent 实例并行审时，对"低/中/高 + 0–100"的刻度解释会漂移（同一本书 3 段并行审：段 1 压在 20–32、段 2 给到 38–45、段 3 跨度 22–62，跨段绝对分不可比）。以下锚点用于校准：

| 分 | 含义 | 锚点样本 |
|---|---|---|
| **85+** | 典型裸 AI 输出 | 大量 delve/tapestry + 总分总 + 说教结尾 + 可能残留引导语 |
| **60** | 单点高危 / AI 生成后轻度润色 | case A-07.2-01（5 连排比 + 单字揭晓式收束） |
| **40** | 风格化但有明显结构性 tic | case A-09.3-01（A-01/A-09 全程癖好级） |
| **25** | 高品质，偶发触发 | case A-01.3-01（高品质文学文本，偶发触发） |
| **15** | 强文体 + 强人味 | case G-03-01（文白相间，Layer D 满格） |

**多 agent 并行审全书的规矩**：开审前先让所有实例对**同一 1–2 章**打分对齐到上表锚点，再展开；或全书由**单 agent 串行**跑（保刻度一致）。

> ⚠️ 权重是经验初值，校准口径是**"命中该特征时，被网友指认为 AI 的风险有多高"**（舆论口径），不是"客观上是 AI 的概率"。建议用 `regression/cases/` + 公开 AI 生成样本，对照真实吐槽案例标定每个维度的诊断价值。
