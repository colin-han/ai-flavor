## 说明

C-01 判的是**具体细节密度**：低分＝满篇抽象概念，没有具体的人名 / 数字 / 场景；高分＝有"星期二、洗衣店、祖母"这类可指认的实物。判官打 1–5 分，≤2 命中。

**before 为什么是 1–2 分**：全文 500 余字，专有名词 0 个、数字 0 个、可视场景 0 处。发起人是"社区内的热心居民"，人数是"比较有限"→"持续增长"→"一定的规模"，场地是"公共空间较为紧张"经"多方协调"后"得到了妥善解决"，书是"主要依靠居民的自愿捐赠"且"数量和种类都比较丰富"。每一句都在描述一件真实发生过的事，却没有一个词能让读者在脑子里画出画面——连"谁协调的、协调到了什么"都被"相关方面最终提供了必要的支持"吞掉。收尾整段是"丰富了精神文化生活／增强了邻里互动／提升了凝聚力和归属感"，纯抽象名词堆叠。这是 C-01 的教科书低分形态，我给 **1 分**。

**after 为什么是 4–5 分**：同样的事件序列，每一环都落到可指认的实物上——发起人有名有姓有履历（三号楼 302 的周惠兰，二十六中语文教师），发起动作有物证（A4 纸、手机号末位 4471），人数是 5 → 23 → 31，人物有脸（八十二岁只听不说话的老蒯、被妈拎来的李婷家小三女儿），场地是"东门那排废弃自行车棚，二十来平方，顶棚漏"，修顶棚花了六百四十块、收据夹在借书登记本第一页，长桌是缺一条腿的旧乒乓球台、垫四块红砖，书九百多本、七纸箱九十年代译林版、潘家园三块五一斤。结尾也不是升华，而是一个具体的未决问题（棚子没暖气，去年一月只来七个人，今年想搬进自行车库还没谈成）。我给 **5 分**。这同时是 D-01（具体细节：品牌 / 数字 / 地址 / 物件）的强正例。

**两版事实层面如何保持一致**：事件序列逐项对齐——① 由居民自发发起；② 初期人少、后来增长、年龄跨度大；③ 场地一度困难、后经协调解决；④ 图书来自居民捐赠、另有外部渠道补充、少儿书是短板；⑤ 现状与后续。before 用抽象概括覆盖这五环，after 用实物覆盖同样五环，没有引入序列之外的新事件。需要说明的是，**C-01 的性质决定了"具体化"必然伴随专名与数字的出现**——"六百四十块"这类细节在 before 中并不存在对应值，因为 before 恰恰是把它抹成了"必要的支持"。这不算新增事实，而是同一事实的两种分辨率。

**边界**：C-01 判的不是"字多不多"，也不是"有没有数字"。①**假具体不算**：把 before 改成"参与人数增长了 360%""覆盖 3 个年龄段"仍是低分——统计口径的数字是抽象的另一种形态，C-01 要的是感官上可指认的东西。②**具体但不服务于叙述的细节堆砌**会滑向另一端：如果 after 每句都塞品牌与型号却不推进事件，那是清单不是场景，判官应下调而非上调。③ after 有意保留了"办到今天是第十四个月""登记在册的现在有九百多本"这类概括句——C-01 高分不要求消灭所有概括，只要求概括句下面有实物托底。
