## 说明

本 case 是全部 G 类里唯一的 **before/after 受控对照**，验证 rules.md 的 **R-02 文体先验档 G-05（营销 / 公关稿，Layer A ×1.2）**——这是五档文体先验里唯一的**升权**档，理由是"本就是 AI 重灾区，正向加权"。它要防的实现缺陷有两个方向：把营销文当普通文本（漏掉 ×1.2），或者把 ×1.2 当成"营销文一律高分"（对干净的营销文误杀）。因此 `after.md` 仍然是营销文、仍然必须命中 G-05，但 A-04.1 与 A-11 必须清零。

### 一、文体判定依据（两侧都必须命中 G-05）

before 与 after 都是**同一产品、同一用途**的推广文：有产品名与型号（静音降噪耳夹 X1）、有卖点与规格、有价格与售后、有面向读者的第二人称或行动引导。after 只是把"喊口号"换成"给数据"，体裁没有变——这是本 case 的设计要点：**降权/升权档判的是文体，不是质量**。

### 二、before：三处命中的量化

| 维度 | 字面证据 | 密度 |
|---|---|---|
| **A-04.1** | 覆盖 rules.md 中文经验清单全部五类共 **27 处**：开头套话（在当今……中 / 毋庸置疑 / 不可否认，3）、过渡（值得注意的是 / 不仅 / 而且 / 与此同时 / 更重要的是 / 由此可见 / 在……的大背景下，7）、总结（综上所述 / 通过以上分析，2）、号召收尾（让我们一起 / 希望这篇……能帮到你，2）、学术八股与翻译腔万能词（首先 / 其次 / 再次 / 最后 / 关键在于 / 我们需要 / 强降噪能力 / 强佩戴支撑 / 强续航表现 / 赋能 / 沉淀 / 闭环 / 底层逻辑 / 长期主义 / 抓手 / 探索，13） | 全文 456 字，**59.2 / 千字** |

```
A-04.1：59.2 /千字 × 1.2（G-05 档 Layer A ×1.2）= 71.0 /千字
```

作为对照，A-04.1-01 的 before 是 47 / 千字（公文体，G-01 ×0.5 后 23.5 / 千字，其 meta 判为"仍在极高位"）。本文字面密度已高于它，再乘 1.2，是回归集内 A-04.1 的最高位样本。A-11 无密度阈值，rules.md 标注"出现即警"，三类形态（bullet / 加粗 / emoji）同时齐备。

### 三、after 改了什么

只做两类改动，产品、结论、体裁均未变：

1. **每一处词表词换成它本该承载的数据**。"强降噪能力 / 赋能"→"地铁车厢本底 78 分贝，开启降噪后耳边约 62 分贝"；"强佩戴支撑"→"单只 8.6 克，夹持力 0.45 牛，12 人连续佩戴 4 小时，9 人无压迫感、2 人第 3 小时后耳廓上缘发红、1 人滑动"；"强续航表现"→"音量 60% 开降噪连续播放 9 小时 12 分，充电盒再充 3 次约 36 小时"；"首先/其次/再次/最后"的四段空转换成"什么情况下不建议买"的三种具体人群；"综上所述 + 让我们一起 + 希望这篇……能帮到你"换成售价、保修、退换、一句明确的推广口径（"本月下单加送一年意外保，进店链接放在文末，觉得上面那三种情况不是你，可以试试。"）与一句"有具体问题可以在评论区问"。
2. **删掉全部格式装饰**。0 个 bullet、0 处加粗、0 个 emoji，改为普通段落。

顺带出现的、而非刻意加入的变化：after 承认了两处缺点（健身房只改善 4~5 分贝、风速超过每秒 5 米时通话断续且"我们没有做到把这个问题解决掉"），并明确划出不建议购买的人群——这是 Layer C 的 C-02（立场明确度）与 C-07（归因实在性）在营销文里的正常形态。

### 五、边界

G-05 的 ×1.2 是**加在 Layer A 命中之上的系数**，不是"营销文起评分更高"。after 的 Layer A 命中为 0，×1.2 之后仍是 0——一篇给数据、认缺点、写清售后的营销文，不该因为它是营销文而被判 AI 味。反过来，before 之所以是回归集内的最高位样本，不是因为它是广告，而是因为删掉 27 处词表词与全部装饰之后，它对产品**没有留下任何可核验的陈述**：降噪多少分贝、8.6 克是单只还是一对、36 小时怎么算出来的，一个都没有。

**为什么 known_other_issues 为空**：`after.md` 是"应不命中"侧文本，其上无其他规则的字面命中——无 markdown 残留、无编号列表与总分总标记词、无开头模板句、无破折号密度异常（全文 1 处）、末段是"有具体问题可以在评论区问"的事务性收束而非升华。before 侧同时命中的 A-08（"在当今快节奏的都市生活中"）、A-06.1（首先/其次/再次/最后）、A-07.1（综上所述 + 号召收尾）随改写一并消失，按 case-common 的字段语义不记入该字段。
