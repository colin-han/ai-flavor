## 说明

A-11 判的是**格式投入与内容体量不匹配**，判据是"bullet / 加粗密度 vs 内容长度"，属出现即警一档（误判风险低），所以文本可以短。

**before 为什么命中**：全部有效信息只有五件事——时间地点、三段流程、不带电脑、禁烟、报名方式，用一段话就能说完；却被拆成 **1 个一级标题 + 4 个二级标题 + 15 个 bullet（含 4 个二级 bullet）+ 9 处加粗 + 13 个 emoji**（🚀✅📌💡🎯🔥🍰⚠️✅✅❌🙋🎉，其中 🚀🔑💡✅ 是条目点名的营销 emoji）。格式标记的数量超过了实际信息条目的数量，是标准的"非内容需要也拆 bullet / 加粗 / emoji"。

**after 改了什么**：把同一批信息还原成四段白描散文，去掉全部 bullet、加粗、emoji 与多级标题。另外补了一句原文没有的、但真实通知里会有的理由（"我好订点心的数量"），因为格式撤掉之后需要有一个人称把话说完。

**after 为什么不再命中**：bullet 0 处、加粗 0 处、emoji 0 处、层级标题 0 处；信息一条没少。

**边界**：A-11 不是"不许用列表"。一份包含二十项配置、每项需要独立查阅的清单，用 bullet 是内容需要，不该命中；判据是格式密度**相对内容体量**是否失衡。另注意与 A-10 的分工：A-10.1/A-10.3 抓的是"残留"（本该被清掉的 markdown 与 Unicode 装饰），A-11 抓的是"作者主动选择的过度格式化"。before 的 `##` 与 emoji 在字面上也会被 A-10.1/A-10.3 的正则扫到——但在这个文本里它们不是残留而是刻意排版，本 case 的目标规则是 A-11。这是 before 侧的附带命中，after 已全部清除，故不记入 known_other_issues。
