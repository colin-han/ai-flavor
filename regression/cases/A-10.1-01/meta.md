## 说明

本 case 一次覆盖 A-10 的三条"硬证据"子规则。A-10 是 rules.md 里**出现即基本实锤**的条目（诊断价值高、误判风险低），且在 §维度级降权表中于 G-02 小说与 G-03 古典文体下均 **×1.0 不降权**——小说正文里出现 markdown 残留就是硬伤。因此本 case 不需要密度论证，逐项列出即可。

**before 的命中清单**：

- **A-10.1 markdown 残留**：`## 第七章　夜里的电话`（正文里的二级标题）、`**陈立冬**`、`**这是本月第三起了。**`（正文加粗）、以及一整个 ``` 围栏代码块。
- **A-10.2 AI 引导语残留**：开篇「以下是续写内容：」、结尾「如果你需要我可以帮你继续写下一章，或者调整本章的节奏。希望对你有帮助！」——都是条目正则直接点名的字符串。另有围栏内的「备注：此处需要补充凶手的心理侧写描写」，是生成过程的中间指令泄漏。
- **A-10.3 Unicode 装饰**：三处 `•` 项目符号、两处 `→` 箭头（"四月二日 → 纺织厂后墙"式与"→ 指向城郊结合部"）。

**after 改了什么**：清掉全部机制残留，并把被 bullet 化的内容还原成叙事。标题去掉 `##`；两处 `**` 加粗去掉；`•` 列表改写成一句带三个时间地点的白描（"四月二日，纺织厂后墙。四月十一日，废弃泵房。今夜，城南废品站。"）；`→` 改成逗号连接；围栏代码块整段删除，并把它提示的"心理侧写"真正写出来一段（红灯时想到围墙是边界），因为留一个空的占位本身也是露馅。首尾两句引导语删除。

**after 为什么不再命中**：`**`、`##`、``` ` ``` ` 各 0 处；引导语正则 0 命中；`→`、`•` 各 0 处。

**边界**：A-10 与 Layer A 其他条目的差别在于它判的是"文本生产过程的痕迹"，不是文风，所以既不看密度也不吃文体降权——一处即命中。唯一的例外由 A-10.4 定义：`[n]` 编号 + 有实质尾注内容的学术脚注属体裁设计，不算露馅（见 A-10.4-01）。
